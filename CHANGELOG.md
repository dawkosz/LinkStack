# Changes

## 1.0.2 — initial experimental GitHub release

- Portable Windows application with a Polish interface, per-link counters, and a live chart.
- Interface-pinned TCP connections over HTTP CONNECT and SOCKS5 proxies.
- Transparent Steam IPv4 TCP 80/443 interception using WinDivert.
- Verified an actual Steam download carrying traffic over Ethernet and Wi-Fi simultaneously.
- HTTP range downloader with validator checks, fallback, cancellation, and temporary-file cleanup.
- Native WinINet proxy snapshots, crash watcher, and orphan-proxy recovery.
- Automatic startup after UAC elevation, preserving selected adapters and weights.
- Local diagnostic status and bounded event log.

This is an experimental first release. No controlled throughput benchmark or broad Windows/Steam compatibility matrix has been completed.
